# Maqueta de pantallas (solo referencia de diseño)

Esta carpeta guarda la primera maqueta de las pantallas de SmartStock ERP,
hecha como página web con datos de prueba. **No es el frontend del
proyecto.** La aplicación final es de **escritorio, con JavaFX**, y se
construye en la carpeta `desktop/`.

## Para qué sirve

- Muestra cómo se verán las 8 pantallas: login, dashboard, productos,
  inventario, movimientos, reposiciones, reportes y usuarios.
- Sirve de guía para diseñar las ventanas de JavaFX.
- Muestra la política FEFO: en Inventario, los lotes aparecen ordenados
  por la fecha de vencimiento más cercana.

## Cómo verla

Abrir el archivo `index.html` en el navegador. No necesita instalación.
Los datos son de prueba y se pierden al recargar la página.

## Importante

No se seguirá desarrollando esta maqueta. Los cambios nuevos van en
`desktop/` (pantallas) y `backend/` (servidor).
