# Diagramas del proyecto

Esta carpeta reúne los diagramas UML y el modelo entidad-relación
sustentados en la Fase 1: casos de uso, clases, componentes, modelo
MVC y modelo entidad-relación.

Los archivos fuente (`.drawio` / `.puml`) se pueden agregar aquí a
medida que se exportan desde draw.io o PlantUML, junto con su versión
`.png` para consulta rápida sin abrir la herramienta.

Sugerencia de nombres al agregarlos:
- `01-casos-de-uso.drawio` / `.png`
- `02-clases.drawio` / `.png`
- `03-componentes.puml` / `.png`
- `04-entidad-relacion.drawio` / `.png`
- `05-mvc.drawio` / `.png`
